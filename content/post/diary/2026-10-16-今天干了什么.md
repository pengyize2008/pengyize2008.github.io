记录一下这个站点怎么用，免得下次又忘了。

## 新建一篇日记

在站点目录 `D:\qinna` 下打开终端，执行：

```bash
hugo new content post/diary/2026-10-16-日记标题.md
```

然后编辑 `content/post/diary/` 下刚生成的文件即可。front matter 里的
`title` 可以改成中文标题，正文用 Markdown 写。

## 本地预览

```bash
hugo server -D
```

浏览器打开 <http://localhost:1313> 就能实时预览，改完文件会自动刷新。
`-D` 表示连草稿（`draft: true`）一起显示。

## 发布

```bash
git add -A
git commit -m "新日记"
git push
```

推送后 GitHub Actions 会自动构建并发布到
[pengyize.是.gay](https://pengyize.xn--0iv.gay/)。

想在本地先生成 `public/` 看一眼也可以跑 `hugo`，不过推上去之后 Actions 会重新构建，
本地产物不参与部署。
